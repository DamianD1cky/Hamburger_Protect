# 透视背景

`renderer.js` 改编自工作区 `perspective_recreation/renderer.js`，保持路口 7 秒、
车站 9⅓ 秒的艺术化透视轨迹。它用 Canvas 2D 重绘几何，纵深与消失点独立变化，
不是公告板的 3D 相机。背景透视不会改变便签坐标或跑团规则。

房间配置保存 `room.kind = "perspective"`、`room.scene = "crossing" | "station"` 和
`room.animated`。原有图片、纯色和门店背景继续使用既有渲染器。

性能边界：

- 切换到透视场景后才懒加载绘图代码，不打包 HTML 播放器、MP4、参考视频或截图。
- 几何与深度排序缓存复用；车站最多保留一份当前配色几何，避免逐帧缓存增长。
- 原画面是 16:9，支持铺满/完整显示与焦点；画布最长宽度 1280，手机上限 960，
  设置预览上限 480。不会按高 DPI 无限分配像素。
- 桌面最多 24 帧/秒，窄屏最多 15 帧/秒；构图没有变化时跳过绘制。
- 页面隐藏、对话框打开或公告板指针操作中暂停，关闭/松开后从同一时刻恢复。
- 预览仅绘制静态构图；禁用动态或系统减少动态效果时不启动动画循环。
- 不传输逐帧状态。房间共享场景选择，每个客户端独立播放。

卸载时取消动画、观察器和事件监听，清空画布。原始复刻目录保持独立。
