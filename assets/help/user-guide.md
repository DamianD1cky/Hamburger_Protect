# VeilBoard（帷幕告示板）新用户帮助

适用版本：2026-11-17。面向玩家、GM，以及需要处理 GM 申请的站长。

VeilBoard（帷幕告示板）是面向多规则跑团使用的共享桌面公告板。GM 负责建局、自由编排区块、布置任务委托与整理现场场景；玩家在同一张告示板上认领委托、维护共享物资、勾选检查项、张贴线索便签并投掷 3D 骰子。新战役默认采用中性软木与木框外观；建房或房间配置中也可选用内置的“危机营业”经典汉堡店主题包。

正式入口：[hamburger.damiandicky.site](https://hamburger.damiandicky.site)

备用入口：[hamburger-protect.vercel.app](https://hamburger-protect.vercel.app)

## 1. 第一次使用：先完成这几步

登录页标题旁的“使用指南”可以在注册前打开；进入战役后，顶部问号“帮助”打开同一份指南。输入关键词可搜索到具体方法或常见问题，点击结果定位到段落；也可以按章节查阅。关闭帮助后返回原页面，当前填写内容和房间视图会保留。

### 我是玩家

1. 打开正式站，点击“注册”。填写账号名、昵称、密码和确认密码，完成注册；已有账号直接登录。
2. 选择“玩家参与”，填写本场角色名、身份 / 职业称呼和 GM 提供的 **6 位房间码**（旧版称班次码），点击“申请加入房间”。
3. 等待房间 GM 批准。可点击“刷新加入审批结果”；批准后从“我的战役”进入对应房间。
4. 进入公告板后，先看“委托与行动报告”和“可用物资与设施”。文字没显示完整时，打开条目或点击“查看更多”。
5. 要执行任务，点击任务左侧的操作按钮领取；行动完成后提交审核。要记录行动经过或线索，点击右下角“便签”。
6. 要投骰，点击右下角“骰盘”。先确认“谁能查看”，再投掷。

**加入房间不是自动批准。** 如果尚未看到公告板，先检查审批状态，不必重复注册账号。

### 我是 GM

1. 注册并登录账号，选择“GM / 主持人”，点击“申请成为 GM”。
2. 联系站长核对账号名，等待审批；批准后点击“刷新审批结果”。
3. 选择开局主题包（默认“帷幕软木”，也可选“危机营业”），填写战役名称、GM 角色名与身份称呼，点击“创建战役并展开告示板”。
4. 复制顶栏的房间码发给玩家。玩家提交后，打开顶栏“成员名册” → “加入申请”，核对并批准。
5. 按住模块标题栏自由调整排版，给模块改名、设置颜色，添加几条物资、检查项和任务委托。需要追踪事态时，在“事件钟”标题栏编辑中发起事件钟。

**最小开局配置**：一个战役、一条任务委托、几项共享物资。其他模块可以按团的需要逐步启用或隐藏。

### 我只想看看

登录后从大厅左侧的“公开参观房间”选择房间，或打开 GM 分享的公开参观链接。参观不需要房间码，也不需要该房间 GM 审批，但只能查看公告板和发送访客留言。

## 2. 账号、角色与审批

### 三种名字分别做什么

| 名称 | 用途 | 在哪里修改 |
| --- | --- | --- |
| 账号名 | 登录身份。3–20 位小写字母、数字、下划线或短横线 | 注册时确定；当前账号设置不提供修改账号名 |
| 账号昵称 | 通行大厅的账号展示名称 | 大厅 → 账号设置 → 保存昵称 |
| 本场角色名 | 这场战役中使用的角色身份 | 成员名册 → 选自己 → 铅笔 → 保存资料 |

角色名和身份称呼可以因战役而不同。修改账号昵称，不会同步改掉各战役的角色名。

注册时的新密码至少 **15 个字符**，最多 **72 个 UTF-8 字节**；中文字符通常占 3 个字节。可以使用长口令，建议保存在密码管理器里。旧账号登录使用已有密码，修改密码时需要满足新的长度要求。

### 两种审批不要混淆

| 申请 | 谁来审批 | 通过后获得什么 |
| --- | --- | --- |
| 申请成为 GM | 站长 | 创建战役及担任 GM 的资格 |
| 申请加入房间 | 该房间 GM | 以玩家身份进入这个战役 |

取得 GM 资格，不会让你自动成为别人房间的 GM。**你的操作权限取决于当前战役中的角色。**

同一账号可以管理不同战役，但同时只能以玩家身份参与 **一场进行中的战役**。已有待审批加入申请时，应先等待结果，或点击“撤回加入申请”后再申请其他房间。

### 后续登录与找回密码

退出后再次登录，在“我的战役”中选择原战役即可，不需要重新填房间码。顶栏的返回箭头只是返回大厅 / 我的战役，不会退出账号或退出房间成员关系。

忘记密码时，点击登录页“忘记密码？”，联系站长并提供账号名和原战役信息。**当前没有邮件自助找回流程。** 不要发送旧密码；由站长通过已有联系渠道核实本人后处理。

## 3. 认识公告板和操作入口

公告板是一张固定比例的共享板面。窗口大小和手机区域切换只改变你看到的范围，不会改变物件的相对位置。

### 顶部菜单

桌面上，鼠标停在图标上可以看到提示。顶部菜单可直接切换；点击窗口外或按 `Esc` 收起。手机上会以完整表单打开，用右上角“关闭”或“完成”返回。

| 入口 | 图标特征 | 主要用途 |
| --- | --- | --- |
| 复制房间码 | 两张重叠纸片 | 分享给需要正式加入的玩家 |
| 成员名册 | 人物与加号 | 看成员资料；GM 处理加入申请 |
| 公告板区块 | 四格 | GM 显示 / 隐藏模块，恢复隐藏区块 |
| 房间配置 | 齿轮 | GM 修改战役名称、公开参观和共享外观 |
| 访客留言 | 对话框 | 发布留言；GM 删除留言 |
| 桌面手册 | 书本 | 查看帷幕桌面协作速查与危机营业附册 |
| 帮助 | 圆圈问号 | 搜索使用方法、查看使用指南 |
| 返回 | 向左箭头 | 返回大厅或我的战役 |

右上角另有 **战役时钟**。它的齿轮只设置时钟，和“房间配置”齿轮不是同一个入口。

### 右下角工具

| 工具 | 图标特征 | 操作 |
| --- | --- | --- |
| 贴纸 | 带加号的笑脸 | 选择 Emoji，再点击板面放置 |
| 便签 | 加号 | 填写自由便签、行动经过或线索 |
| 便签栏 | 列表 | 查看全部便签；GM 可置顶便签 |
| 骰盘 | 骰子 | 打开独立 3D 骰盘 |

只读参观时，编辑和骰盘等入口会隐藏。缺少某个按钮时，先确认自己是不是以公开参观方式进入。

### 标题栏编辑与内容操作

模块标题栏的 **铅笔** 是 GM 的统一编辑入口；眼睛带斜线的按钮隐藏模块。内容卡片负责查看明细、领取任务、勾选检查项等日常操作。

模块编辑窗口分为“外观”和“内容”：

- “外观”修改模块标题和标题底色，点击“保存模块外观”生效。
- “内容”按模块提供物资分类、检查项、事件钟等设置，使用各自的保存按钮。
- **保存外观不会顺便保存内容草稿。** 改完分类标题还需要“保存分类标题”，改完事件钟还需要“保存事件钟”。

模块名称可以由 GM 自定义。本文使用默认名称；例如“物资”“线索”“日常检查”可能是同一模块在不同房间中的新名字。

### 摘要不是完整列表

| 模块 | 公告板上的显示方式 | 如何看完整内容 |
| --- | --- | --- |
| 物资 | 每个分类最多 3 项，显示分类总数 | 查看明细 / 查看更多 |
| 委托与行动报告 | “进行中”“已完成”每栏最多 4 项 | 点击任务或查看更多 |
| 行动检查清单 | 最多 8 项，分类写在每行右侧 | 查看更多 |
| 行动记录 | 最近 5 条操作记录 | 点击卡片或查看更多；可加载更早记录 |
| 成员名册 | 最多 3 位在场成员 | 点击卡片或顶部成员名册 |
| 事件钟 | 每个事件钟独立成卡片，同时显示 | 各卡片的查看详情 / 查看后果 |

公告板卡片不通过内部滚动展示全部条目。**条目变多后，未显示的内容仍然存在。**

## 4. 委托与行动报告：领取、提交、审核

### GM 发布任务

1. 在“委托与行动报告”的“进行中”卡片里点击加号，或打开模块标题栏编辑并选择“发布任务委托”。
2. 填写标题、内容、负责人和完成时间。标题与内容必填；负责人是说明性信息，实际领取后会显示领取者。
3. 点击“保存”。玩家随后可以看到任务并领取。

修改已发布任务，点击任务文字区域；GM 会进入“编辑任务委托”。撤下任务时使用明确的删除按钮，并确认删除。

### 玩家完成任务

1. 点击任务文字，阅读完整说明。
2. 在“可领取”任务左侧点击圆形操作按钮。领取成功后会显示你的角色身份。
3. 完成行动后，在自己领取的任务上点击“提交审核”。
4. 任务变为“待审核”，等待 GM 处理。

你不能提交别人领取的任务。两个玩家同时领取时，以成功保存的领取者为准；失败者应重新查看最新状态。

### GM 审核

- **审核通过**：任务进入“已完成”栏。
- **退回任务重试**：任务变为“需重试”，原领取者可以继续处理后再次提交。
- **重新开放**：GM 可将已完成或需重试的任务恢复为可领取状态。

标准流程：**可领取 → 已领取 → 待审核 → 已完成**。需要返工时，由待审核退回“需重试”。

**“提交审核”目前提交的是任务状态，没有附加报告正文输入框。** 若需记录过程、消耗、发现或判断，请同时写一张便签，并用标题关联任务。

## 5. 物资、行动检查清单与行动记录

### 物资与设施

默认有“装备与补给”“线索与道具”“设施与资产”三个分类（“危机营业”主题包默认为食材、设施与工具），GM 可以重命名。GM 与在场玩家都能维护分类内的物资条目。

1. 点击分类卡片的“查看明细”或“查看更多”。
2. 点击“＋ 添加条目”，填写名称、数量与单位、状态。
3. 点击“保存条目”。修改已有条目同样单独保存。
4. 需要删除时，点击“删除条目”，再点击“确认删除条目”。

| 状态 | 含义 |
| --- | --- |
| 已备 | 当前可用 |
| 待补 | 需要补充或关注 |
| 耗尽 | 当前不可用 |

“数量与单位”是文本，例如“12 瓶”“半箱”“可用 3 次”。**系统不会根据任务完成或投骰自动扣物资，也不会自动计算库存。** 用掉物资后由成员更新。

### 行动检查清单

玩家日常使用：点击检查项左侧方框 / 条目，标记完成；再点一次取消完成。进度以“已完成数 / 总数”显示，队友能看到更新。

GM 编辑清单：

1. 点击“行动检查清单”标题栏铅笔。
2. 在“内容”区选择“新增条目”或“修改条目”。
3. 填写检查内容并选择分类，使用对应保存按钮。
4. 分类名称和分类增删在同一内容区维护。

删除分类会让其检查项转入未分类，**不会自动删除该分类中的检查项**。日期变化也不会自动重置勾选状态，需要成员自行取消完成。

### 行动记录：自动操作日志

这里记录谁对公告板做了什么，例如新增便签、修改物资、完成检查项或调整事件钟。

- 点击卡片或“查看更多”查看完整记录。
- 打开“查看变更内容”，可查看有记录的修改前后内容。
- 点击“加载更早记录”继续查看较早的操作。

**行动记录不是手写日记，也不能像便签那样直接编辑。** 标题栏铅笔修改的是该模块的外观。需要添加自己的叙述时，请使用右下角“便签”。

## 6. 便签、连线与 Emoji 贴纸

### 新建与编辑便签

1. 点击右下角加号“便签”，填写标题和内容。
2. 选择便签颜色、图钉颜色；需要照片时点“插入照片”。
3. 点击“保存”。带照片的便签会以拍立得样式显示。

照片支持 JPEG、PNG、WebP，上传前会压缩；标题作为照片说明。已有便签可以单击 / 点按打开编辑，或者通过“便签栏”找到“编辑便签”。

玩家只能编辑、移动、调整层级或删除自己的便签；GM 可以处理所有便签。便签保存失败时，编辑器会保留草稿供重试，但不要在未保存时刷新整个网页。

### 移动、层级与置顶

- **移动**：按住便签正文拖到新位置，松开保存。桌面和手机均可拖动。
- **层级**：便签底部“上移一层”“下移一层”控制重叠时的前后关系。
- **置顶**：GM 在“便签栏”里点击图钉图标，优先排列重要便签；再点取消置顶。

便签顶端的彩色图钉用于 **建立连线**；便签栏里的图钉按钮用于 **置顶列表**，两者不同。

### 用连线整理线索

1. 点击第一张便签顶部的图钉，开始连线。
2. 点击第二张便签的图钉，完成连接。
3. 在出现的关系纸片上填写简短说明，最多 24 个字符。按 `Enter` 或点击其他位置保存。

连线可以由在岗成员建立，包括连接其他成员的便签；这不会赋予你修改那些便签正文的权限。

点击连线或关系纸片可修改说明。删除连接需要打开编辑后点击垃圾桶“删除连线”；**单击连线不会删除它**。开始拉线后按 `Esc`，或再次点击起点图钉，可以取消。

### 放置、缩放与旋转贴纸

1. 点击右下角“贴纸”，选择一个 Emoji。
2. 点击公告板上的位置完成放置。
3. 按住贴纸拖动可移动；悬停、点选或聚焦贴纸后可看到大小和旋转控件。
4. 用 `−` / `＋` 调整大小，范围 **50%–250%**；点击百分比恢复 100%。
5. 用逆时针／顺时针按钮旋转，每次 **15°**，支持完整一圈；点击中间角度恢复为 0°。
6. 点击贴纸的 `×` 删除。

贴纸位置、大小和角度在战役内共享。旋转后缩放或移动会保留角度，操作失败时恢复原状态。选择 Emoji 后尚未放置时，按 `Esc` 取消。

## 7. 骰盘：普通投掷、公式与全员检定

### 第一次投掷

1. 点击右下角“骰盘”。
2. 有骰子时可以直接点“投掷全部”；空骰盘通过右上角“更多” → “添加骰子”选择骰型。
3. 单击骰子，打开扇形菜单。点“设置”填写总修正、用途和“谁能查看”。
4. 点“投掷” / “重投”，或按住骰子约 350 毫秒后拖起，再松手投掷。

只选中一颗或一组骰子时，可以只投掷选中部分；未选中的骰子保留原来的位置和结果。

投掷结果由服务器确定，拖动方向和速度影响动画轨迹，**不能通过拖动操控点数**。底部显示各骰子的类型、点数、修正和总结果；完整明细在“更多” → “投掷记录”。

### 先确定谁能看结果

| 选项 | 谁能查看结果 |
| --- | --- |
| 全员可见 | 当前战役中有骰盘访问权限的成员 |
| 我和 GM | 投掷者和 GM |
| 暗骰 · 仅 GM | GM；普通玩家投掷者也看不到自己的结果 |
| 仅自己 | 投掷者；其他人，包括不是投掷者的 GM，不能查看 |

公开参观者没有骰盘入口。“全员可见”不是把骰子结果公开给整个互联网。

暗骰或私骰在你的界面中不显示结果，不代表投掷失败。具备公开权限的用户可通过“公开结果”让战役成员查看；**公开后不要再将该结果视为秘密**。

### 多选骰子

桌面：

- 在骰盘空白处按住鼠标拖框，选择一组骰子。
- `Shift` 拖框可以追加选择。
- `Shift`、`Ctrl` 或 `⌘` 点击骰子可以切换其选中状态。
- 对选中骰子使用“设置”，统一填写总修正、用途和可见范围，再投掷。

手机：

1. 点击骰盘顶部“多选”。
2. 逐颗点选 / 取消，或使用“全选”“清除选择”。
3. 点击底部“投掷选中”，或点“完成”回到选中组的扇形菜单。

“总修正”只对这次选中组加一次，例如 `1d6+1d20+3`，不是每颗骰子各加 3。d100 的两颗骰子按一组选择。

### 骰型与骰盘容量

可添加 d4、d6、d8、d10、d12、d20、d100 和 dF。d100 用十位骰和个位骰表示：十位显示 00–90，两颗均为 0 表示 100；dF 使用负、零、正结果。

骰盘最多摆放 **20 颗实际骰体**，d100 占两个位置。需要更多骰子时使用公式；公式每次最多请求 100 颗骰子。超过骰盘能展示的规模或使用特殊骰面时，到投掷记录看完整结果。

“移出”只移走当前骰盘里的骰子，**不会删除历史投掷记录**。

### 常用公式

打开“更多” → “公式与预设”，直接填写公式，也可以先设置数量和修正再点击骰型快捷按钮。

| 公式 | 含义 |
| --- | --- |
| `1d20+5` | 一颗 d20，再加 5 |
| `2d20kh1` | 两颗 d20，保留最高一颗 |
| `2d20kl1` | 两颗 d20，保留最低一颗 |
| `4d6dl1` | 四颗 d6，舍弃最低一颗 |
| `6d6>=5` | 六颗 d6，统计达到 5 或以上的成功数 |
| `1d6!` | 爆炸骰：掷到最大面时继续追加 |
| `4dF` | 四颗 Fate 骰 |

特殊规则的“结果”可能是成功数等计算值，不能只把可见点数相加。具体采用哪种公式，由本团规则和 GM 决定。

### 预设、记录和显示偏好

- 常用公式点击“保存为预设”，输入预设名称后保存。
- GM 可勾选“房间共享”给成员使用；未共享预设属于创建者。
- 点击预设会带入公式、用途和可见性，**还需要点击投掷**。
- “投掷记录”可展开明细、重投、在骰盘查看；需要时加载“更早记录”。
- “声音”开关和青玉、象牙、黑曜石、霓虹皮肤属于本机显示偏好，不改变点数或房间规则。

### 全员检定

GM 打开“更多” → “全员检定”，填写检定名称、公式、可见性，勾选要参与的在岗玩家，点击“发起检定”。

被选中的玩家会看到待检定提示；打开检定面板点“响应检定”。名单显示谁已投出、谁待投掷。GM 可点击“结束检定”，结束后不能继续响应。

“全员检定”实际使用 GM 勾选的名单，并不会强制每个房间成员都参与。

### 表情互动和投掷失败

骰盘显示成员的名字头像和近期投掷状态。没有正在投掷时，点击 **自己的头像** 可以发 Emoji，短暂同步到本战役。不能替其他成员发送表情。

出现“正在准备…”时等待结果确认。网络失败后优先使用“重试这次投掷”或“继续这次投掷”；它们继续同一次准备好的请求。普通“重投”会产生新的投掷记录，两者含义不同。

<a id="clocks"></a>
## 8. 战役时钟与事件钟

### 战役时钟：日期和计时

GM 点击右上角时钟的齿轮，选择模式：

| 模式 | 用途 |
| --- | --- |
| 时钟 | 战役日期和时间随现实经过的时间向前运行 |
| 倒计时 | 从设定时长向下计，到零结束 |
| 正计时 | 从设定时长向上计 |

纪元是两个英文字母，例如 `AD`、`UC`；纪年为 0–9999。时钟模式中：

- 输入纪年，日期中的年份自动对齐，月、日、时分秒保留。
- 修改日期年份，纪年同步更新。
- 闰日换到平年时自动调整为 2 月 28 日。
- 运行跨年时，纪年随日期递增。
- 0000 年采用月、日、时间输入，其余年份使用日期与时间控件。

用“开始”“暂停”控制运行；“复位”回到设定的起始值并暂停。选择辉光管、石英或数字外观后，点击“保存共享时钟”，房间成员会看到共享更新。

**战役时钟不会自动推进事件钟、扣除物资或重置检查清单。** 倒计时结束也不会代替 GM 执行规则后果。

### 事件钟：事态进度

事件钟适合追踪警戒、追捕、修复、调查等进展，由 GM 手动控制。玩家和公开参观者可以查看，不能增减进度。

GM 发起事件钟：

1. 点击“事件钟”标题栏铅笔。
2. 在内容区选择新建入口“发起事件钟”。
3. 填写事件名称、总格数、起始进度、颜色和填满后的后果。
4. 点击表单中的“发起事件钟”。修改已有事件钟用“保存事件钟”。

总格数为 **2–24**，起始进度可从 0 开始，也可从 1/6 等中途状态开始；每个战役最多保留 24 个事件钟。

例如：名称“被追捕”，总格数 6，起始进度 1，后果“追兵发现藏身处，进入冲突”。这是规则使用示例，可以换成任何团的事件。

日常推进：

- GM 在卡片内使用 `＋` / `−` 增减进度。
- 每个事件钟单独成卡片，同时保留在板面上；新增不会切换或覆盖旧卡片。GM 可拖动各卡片标题栏，移动或删除一张不会重排其他卡片。
- 点某张卡片的铅笔直接编辑这个事件钟。标题栏“隐藏”仍隐藏整个事件钟区块；只移除一张时使用编辑表单中的“移除事件钟”。
- 点“查看详情”看完整描述，填满后显示醒目的“事件已满”和“查看后果”。
- 回退进度会取消满格高亮，并留下操作记录。

**满格提示只提醒后果，不会自动替 GM 执行剧情或规则。**

旧房间的“汉堡屋指数”保留为状态刻度，有原来的阶段名称和说明；它不是“填到最后就触发危险”的进度钟。新房间不默认创建这个指数。

<a id="gm"></a>
## 9. GM：整理房间与共享外观

### 建议的开局顺序

1. 确认玩家加入和角色资料。
2. 给模块与物资分类改成适合本团的名字。
3. 填写物资和检查项，发布初始任务。
4. 张贴重要说明和线索，必要时连接关系。
5. 需要时配置战役时间和事件钟。
6. 最后调整外观和公开参观范围。

### 移动与隐藏模块

按住模块标题栏文字所在区域拖动，松开保存位置。模块会吸附到网格，并在放下时避开其他模块；标题栏上的按钮仍是点击操作。

点击标题栏隐藏按钮可以暂时藏起整个模块。顶部“公告板区块”能恢复显示，包括便签区。

**隐藏不等于删除，也不等于保密。** 数据仍保留；需要公开参观的房间，应先检查所有可展示的内容，不能把隐藏区块当成秘密资料的权限开关。

### 修改房间外观

打开顶部“房间配置”：

- “房间”页修改战役名称、管理公开参观，并可转到成员资料。
- “外观”页支持一键套用主题预设（帷幕软木、暗影黑板、羊皮卷宗、危机营业），也可单独配置房间背景、板面材质、边框和便签纸张。
- 房间背景可用门店、纯色、自定义图片、路口或车站。路口 / 车站可选择动态透视。
- 板面可用黑板、软木、纸张或自定义纹理；边框可选木框、金属、无边框或经典汉堡店边框。
- 调整暗化、适配方式和焦点，让正文更容易看清。

自定义背景和板面纹理支持 JPEG、PNG、WebP，选择时的原文件不能超过 20 MiB。选图和样式预览不会立即上传或改变共享板面，点击“保存共享配置”后才保存。

动态背景在部分操作或后台状态下会暂停；系统开启减少动态效果时会显示静态画面，这是正常行为。

### 保存、草稿与多人编辑

| 操作 | 生效方式 |
| --- | --- |
| 模块标题 / 底色 | 保存模块外观 |
| 物资分类标题 | 保存分类标题 |
| 物资、检查项、便签、事件钟 | 使用各自表单保存 |
| 模块、便签、贴纸拖动 | 松开后保存 |
| 检查勾选、事件钟加减、区块显隐 | 操作后直接更新 |
| 公开参观开关、便签纸张上传 / 恢复默认 | 直接保存，不等待“保存共享配置” |
| 房间名称、背景、板面、边框 | 保存共享配置 |

房间设置通过点外部或关闭按钮收起时，会保留尚未保存的草稿；点“取消”才丢弃该房间设置草稿。角色资料编辑和访客留言也支持收起后继续填写。

**不要把“关闭后保留”理解成刷新网页也会保留。** 刷新、退出账号或切换战役可能丢弃未保存草稿，离开前应使用保存按钮。

多个 GM 同时改同一配置或事件钟时，过期草稿可能提示冲突。重新打开、查看最新内容后再改；不要反复用旧窗口覆盖别人的修改。

### 成员与两类管理

“成员名册”中的“成员”页可查看成员资料；成员自行编辑自己的角色名、身份称呼和介绍。GM 在“加入申请”页批准或拒绝玩家，必要时添加审批备注。

GM 可移出在场玩家。移出前会显示未完成任务数量；尚未提交的任务会释放，待审核任务保留给 GM 处理。成员移出使用明确的确认按钮。

站长的“GM 申请审批”位于 **大厅“账号设置”旁**，包括“待审批”“已处理”。普通 GM 看不到此入口；站长批准 GM 资格，也不会自动成为对方战役的成员。

## 10. 公开参观和访客留言

GM 在“房间配置” → “房间”打开“公开参观”，再点“复制参观链接”分享。

**房间码给玩家正式加入；参观链接给只读访客。** 持有参观链接不会自动获得玩家权限。即使你有 GM 资格，用公开参观入口进入别人房间时也是只读访客。

| 操作 | 本房间 GM | 在场玩家 | 公开参观者 |
| --- | --- | --- | --- |
| 查看可见公告板和明细 | 可以 | 可以 | 可以 |
| 配置模块与房间外观 | 可以 | 不可以 | 不可以 |
| 发布 / 审核任务委托 | 可以 | 不可以 | 不可以 |
| 领取、提交自己的任务 | 不使用玩家流程 | 可以 | 不可以 |
| 更新物资、勾选检查项 | 可以 | 可以 | 不可以 |
| 新建便签 | 可以 | 可以 | 不可以 |
| 编辑 / 移动便签 | 全部便签 | 自己的便签 | 不可以 |
| 便签连线、Emoji 贴纸 | 可以 | 可以 | 不可以 |
| 调整事件钟或战役时钟 | 可以 | 不可以 | 不可以 |
| 使用骰盘 | 可以 | 可以 | 不可以 |
| 发布访客留言 | 可以 | 房间公开时可以 | 可以 |
| 删除访客留言 | 可以 | 不可以 | 不可以 |

发布留言：打开顶部“访客留言”，填写署名与留言，点击“发布留言”。留言最多 500 个字符，短时间连续发送会受到限制；提示过快时等待约 30 秒后重试。

GM 可在留言旁点垃圾桶删除。普通玩家和参观者没有留言管理权限。

公开前请检查便签、角色相关信息和行动记录是否适合展示，不要在准备公开的板面上存放账号密码或需要保密的个人信息。

## 11. 手机操作与快捷方式

### 手机上先切区域，再操作

底部导航：“全览”“物资”“任务”“成员”“事件”“检查”“记录”；没有事件钟时不显示“事件”。

- “全览”查看整张公告板。
- “成员”同时聚焦成员名册和事件钟。
- “事件”聚焦单张事件钟；有多个时用上方的名称选项选择要看的卡片，其他卡片仍留在板面。
- “记录”聚焦自动行动记录；全部自由便签从右下角“便签栏”打开。
- 模块被隐藏后，其对应区域入口也可能消失，请由 GM 恢复区块。

长列表和长说明通过“查看更多”“查看详情”打开，不需要在固定公告板卡片里滑动找内容。弹出表单可以滚动；保存、完成或关闭后返回公告板。

### 快捷方式速查

| 情境 | 操作 |
| --- | --- |
| 关闭桌面顶部弹出窗口 | 点外部或 `Esc` |
| 关闭手机弹出表单 | 右上角关闭，或底部完成 |
| 取消便签拖动 / 正在建立的连线 | `Esc` |
| 保存连线关系说明 | `Enter` 或离开输入框 |
| 取消正在编辑的连线说明 | `Esc` |
| 取消尚未放置的贴纸 | `Esc` |
| 桌面骰子多选 | 拖框；`Shift` 拖框追加 |
| 桌面逐颗切换骰子选择 | `Shift` / `Ctrl` / `⌘` 点击 |
| 手机骰子多选 | 顶部多选 → 点选 / 全选 |
| 骰子扇形菜单键盘切换 | 方向键、`Home`、`End` |
| 恢复贴纸原大小 | 点击大小百分比 |
| 恢复贴纸原方向 | 点击旋转角度 |

`Esc` 的作用取决于当前正在进行的操作或打开的面板；它不代表撤销所有已经保存的房间修改。

## 12. 常见问题

### 登录了，但没有看到房间

先确认你从“我的战役”正式进入，还是仅打开了公开参观。玩家申请需要该房间 GM 批准；GM 资格需要站长批准。刷新相应审批结果。仍无结果时，把账号名和战役名称发给对应管理者核对。

### 房间码无效，或者不能再加入另一场

检查房间码是否为 6 位字母 / 数字，向 GM 确认房间仍在进行。已有在场玩家战役时不能再加入第二场；已有待审批申请时，先等待或撤回。

### “新建或加入其他战役”会清空原房间吗

不会。通行大厅该按钮打开新建 / 加入战役的流程，不是重置已有公告板。点击“返回我的战役”可以回到原列表。

### 任务无法领取、提交或审核

先看状态和当前身份：玩家只能提交自己领取的任务，GM 审核待审核任务，公开参观者只读。如果其他人刚刚改过状态，重新查看后再操作。

### 条目新增成功，却没出现在卡片上

卡片只展示摘要。查看总数，再点“查看更多”；物资、任务和检查项完整内容都在明细页。

### 看不到编辑铅笔或骰盘

检查顶栏身份。如果显示“公开参观（只读）”，返回大厅，从正式战役列表进入。模块设置仅 GM 可见，玩家的便签编辑仅对自己的便签开放。

### 模块或便签不见了

GM 到“公告板区块”检查隐藏状态。手机切到“全览”确认位置；自由便签也可从“便签栏”找到。隐藏没有删除内容。

### 暗骰显示“已投出”，没有点数

这是可见范围的正常结果。普通玩家投掷的“暗骰 · 仅 GM”由 GM 看点数；“仅自己”的结果只有投掷者可看。先核对设置，不要因为看不到点数就反复重投。

### 投骰一直准备中，或者失败了

检查网络，优先点击“重试这次投掷” / “继续这次投掷”，不要把普通“重投”当作同一次请求的重试。若被提示频繁操作，稍后重试；公式报错则检查格式和数量上限。

### 纪年和日期不一致，或者小时变了

当前版本会自动联动纪年和日期年份。先刷新到最新版，再打开战役时钟检查；保存后重新打开确认。时钟按浏览器本地时区显示，不同设备时区不同，可能看到不同小时或日期。

### 事件钟填满了，为什么剧情没有自动执行

事件钟只显示后果并记录完成，具体剧情、伤害或规则处理仍由 GM 决定。倒计时结束同样不会自动完成任务。

### 保存时提示“其他 GM 已修改”

这是冲突检查在保护新数据。保留想修改的文字，重新打开编辑窗口查看最新版本，再提交修改；不要持续用原草稿重试。

### 背景图片无法选择或保存

使用 JPEG、PNG、WebP；背景 / 板面原图不要超过 20 MiB。房间背景、板面和边框需要“保存共享配置”。若网络或权限报错，先保留草稿，检查连接和 GM 身份后重试。

### 文档写了“已归档”，界面里却找不到归档按钮

归档是系统支持的战役状态，但当前常规用户界面没有提供自助归档 / 导出入口。若需要结束、归档或迁移一场战役，请联系站长。房间显示已归档时应按只读状态使用，不再继续修改。

### 本地演示可以邀请远端玩家吗

不能。本地演示的数据只保存在当前浏览器，不提供跨设备同步和真实账号流程。正式联机应使用上方在线入口；`127.0.0.1` 地址只能代表当前设备，不能作为发给队友的公网地址。

### 仍然无法解决时，应提供什么

联系 GM 或站长时，提供：战役名称、当前身份、操作入口、提示原文、发生时间、设备和浏览器，以及不含敏感信息的截图。**不要发送密码、登录令牌或带密钥的环境配置。**
